# Yusra Malas — portfolio

Personal site of Yusra Malas, AI Product Engineer. Plain HTML, CSS and JavaScript: **no framework, no build step.**

## Run it

Open `index.html` in a browser, or serve the folder (recommended, the lab previews and the contact form need http):

```bash
npx serve .
```

## What's in here

| Path | What |
| --- | --- |
| `index.html` | the page markup |
| `lab/` | six standalone pages shown in the Lab section (three briefs, built with and without a design skill) |
| `img/` | photos (see `img/README.txt`; missing files are skipped) |

## Deploy

Hosted on Vercel, deployed from this GitHub repo. No build command, output directory is the repo root.

## Rules for this repo

- No secrets, tokens, chat IDs or `.env` files. Use Vercel environment variables.
- No client screenshots, code or data from NDA work (ISUZU, SawafTECH).
- Only photos Yusra owns.
